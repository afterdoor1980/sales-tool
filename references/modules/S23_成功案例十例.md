> 版本：v1.0（正式稿）

## 与S22的边界说明

本模块的10个案例是用S22的RCA法萃取产出的**最终成果**，只呈现S22模板中的五个字段（案例背景/关键决策点/销冠动作/结果/可复制规律），不展示萃取时的记录层-线索层-抽象层推导过程——推导过程是萃取导师的内部工作方法，详见S22。

## 案例一（甲）：价格异议化解为框架协议

| 字段 | 内容 |
|---|---|
| 编号 | S23-01 |
| 案例背景 | 某中小型机械加工企业，采购经理对报价提出异议，认为比另一家供应商贵，采购金额约60万/年 |
| 关键决策点 | 客户提出"再便宜点"时，销冠没有直接让价，而是先了解客户比价的具体条款是否对等 |
| 销冠动作/话术 | 参照S11-01标准话术追问竞品条款细节，发现对方未考虑补货时效和质检成本，随后引导客户签订年度框架协议（参照S10-03），以量换价而非单纯降价 |
| 结果 | 成交，价格仅小幅调整，客户次年采购量增长30% |
| 可复制规律 | 客户压价时，先确认对比基准是否对等，往往比直接让价更有效，同时框架协议是应对压价的有效替代方案 |

## 案例二（甲）：新人首单突破

| 字段 | 内容 |
|---|---|
| 编号 | S23-02 |
| 案例背景 | 新入职销售（入职2个月），客户为初次接触的中小企业，采购经理最初对"新人对接"表现出疑虑 |
| 关键决策点 | 客户询问"你做这行多久了"，新人没有回避也没有夸大，坦诚说明入职时间不长 |
| 销冠动作/话术 | 参照S26-03新人版话术，强调"公司12年经验+资深同事支持"，并主动提出如遇到解答不了的问题会立即对接资深同事，取得客户初步信任 |
| 结果 | 成交，客户后续反馈"这个新人虽然经验不多，但反应快、靠谱" |
| 可复制规律 | 新人不必掩饰经验不足，坦诚+借力公司体系的话术，比试图伪装资深更容易建立信任 |

## 案例三（甲）：竞品存量客户转化

| 字段 | 内容 |
|---|---|
| 编号 | S23-03 |
| 案例背景 | 客户当时是某竞品的长期合作方，销冠通过行业展会得知信息并主动接触 |
| 关键决策点 | 没有要求客户"立即更换供应商"，而是先建立"低风险备选"的联系定位 |
| 销冠动作/话术 | 参照S20-03话术，表示"不是想说服您马上更换，只是希望有需要备选或对方出现问题时能想到我们"，半年后客户主动因竞品交期问题联系销冠 |
| 结果 | 成交，且后续转为稳定复购客户 |
| 可复制规律 | 争取竞品存量客户不宜急于要求替换，建立低压力联系、耐心等待窗口期，转化成功率更高 |

## 案例四（甲）：客诉转败为胜

| 字段 | 内容 |
|---|---|
| 编号 | S23-04 |
| 案例背景 | 某批次产品出现轻微质量问题，客户情绪激动，一度表示要终止合作 |
| 关键决策点 | 销冠没有立即辩解或强调"这是个例"，而是先安抚情绪、承诺核实 |
| 销冠动作/话术 | 参照S18-11安抚话术，24小时内完成核实并主动提出超出预期的补偿方案（额外质保期延长），而非仅仅按标准流程处理 |
| 结果 | 客户不仅未终止合作，反而因处理态度诚恳成为S15触发的转介绍来源之一 |
| 可复制规律 | 客诉处理得当，反而可能强化客户信任，关键在于响应速度和态度，而非单纯的问题本身是否严重 |

## 案例五（乙）：多角色决策链逐步攻克

| 字段 | 内容 |
|---|---|
| 编号 | S23-05 |
| 案例背景 | 某集团客户自动化改造项目，初期只接触到基层技术对接人，决策链完全不清晰 |
| 关键决策点 | 销冠没有急于推进方案，而是先花两个月时间通过S05方法逐步摸清完整决策链（技术把关人、财务、分管领导） |
| 销冠动作/话术 | 分别针对不同角色采用差异化沟通策略（参照S05-03至S05-06），并通过技术把关人的认可逐步建立向上的信任传递 |
| 结果 | 历时5个月最终中标，项目金额400万 |
| 可复制规律 | 乙类客户决策链复杂时，前期摸清决策链比急于推方案更重要，磨刀不误砍柴工 |

## 案例六（乙）：投标"疑似陪标"逆袭

| 字段 | 内容 |
|---|---|
| 编号 | S23-06 |
| 案例背景 | 某次投标邀请，技术参数明显定制化指向特定竞品，销冠判断疑似陪标信号较强 |
| 关键决策点 | 参照S21第五节陪标判断阈值，虽判定为疑似陪标，但仍决定投入简化资源参与而非放弃 |
| 销冠动作/话术 | 标书重点突出方案与实际工况的匹配度（而非参数堆砌），评标现场坦诚回应报价质询（参照S21-12），意外获得评委认可 |
| 结果 | 中标，事后了解到内定的供应商因资质材料问题被废标 |
| 可复制规律 | 即使疑似陪标也不轻易放弃参与，认真准备仍有逆转可能，且废标风险清单的严格执行往往是决定成败的隐藏因素 |

## 案例七（乙）：技术异议化解带来内部教练

| 字段 | 内容 |
|---|---|
| 编号 | S23-07 |
| 案例背景 | 技术把关人对方案某项配置提出"是否过度设计"的质疑 |
| 关键决策点 | 销冠没有整体辩护，而是主动提议逐项过配置清单，并坦诚承认其中一项确可简化 |
| 销冠动作/话术 | 参照S11-07及S20劣势维度应对策略，逐项透明讨论，赢得技术把关人认可 |
| 结果 | 中标，技术把关人后续主动提醒销冠注意评审流程的关键节点，成为内部教练 |
| 可复制规律 | 面对技术质疑坦诚讨论比整体辩护更容易建立信任，也更可能转化出内部教练关系 |

## 案例八（乙）：战略价值加成促成长期合作

| 字段 | 内容 |
|---|---|
| 编号 | S23-08 |
| 案例背景 | 某客户单次项目金额未达到S类分层标准，但为行业标杆企业，具备显著案例宣传价值 |
| 关键决策点 | 销冠判断该客户存在被低估的战略价值，没有按常规B类资源投入，而是申请分层加成 |
| 销冠动作/话术 | 参照S04第五节战略价值加成规则，向主管提交申请并获批，按上调后的分层投入服务资源（参照S17超预期服务） |
| 结果 | 项目顺利完成，该客户后续成为公司案例库的核心案例，并带来两次同行业转介绍 |
| 可复制规律 | 分层不应完全由单次项目规模决定，识别并申请战略价值加成，能为企业带来超出单笔项目金额的长期价值 |

## 案例九（乙）：严重客诉危机挽回

| 字段 | 内容 |
|---|---|
| 编号 | S23-09 |
| 案例背景 | 项目验收后设备出现故障，客户情绪强烈，提及可能诉诸法律追究责任 |
| 关键决策点 | 销冠第一时间上报公司高层及法务（参照S18严重客诉分级），未自行承诺或对抗 |
| 销冠动作/话术 | 公司高层直接介入沟通，法务同步评估，最终通过快速响应和透明的责任说明达成和解，未升级为法律纠纷 |
| 结果 | 客户关系得以维系，次年该客户还追加了新一期项目 |
| 可复制规律 | 严重级别客诉必须第一时间上报高层，不由一线人员自行承担压力对抗或私自承诺，规范升级流程反而是保住客户关系的关键 |

## 案例十（乙）：长周期客户的耐心跟进转化

| 字段 | 内容 |
|---|---|
| 编号 | S23-10 |
| 案例背景 | 某客户方案讲解会后表示"内部讨论"，此后近4个月无明显进展 |
| 关键决策点 | 销冠没有频繁催促，而是严格按S14跟进节奏（状态确认型与增量信息型交替），持续但不过度打扰 |
| 销冠动作/话术 | 参照S14-05至S14-08节奏，穿插分享行业最新政策动态（增量信息型），维持关系而不施压 |
| 结果 | 第5个月客户主动联系推进，最终签约，客户反馈"就是因为你们一直没有过度催促，让我们感觉很专业，才更倾向选择你们" |
| 可复制规律 | 长周期客户的耐心跟进本身就是一种差异化竞争力，机械催促容易适得其反，恰当的节奏管理能成为加分项而非中性动作 |

## 本模块专属验收细则

| 检查点 | 标准 |
|---|---|
| 场景覆盖多样化 | 10个案例是否覆盖不同类型的成功路径（价格、竞品、客诉、决策链、投标、分层、危机、跟进等），而非重复单一模式 |
| 五字段完整 | 每个案例是否包含案例背景/关键决策点/销冠动作/结果/可复制规律五个字段 |
| 关联其他模块编号 | 案例中的销冠动作是否恰当引用相关话术/流程编号，体现与手册体系的联动 |
| 可复制规律具体 | 每条规律是否具体可操作，而非"用心服务"这类空泛表述 |
| 甲乙分布合理 | 是否体现甲乙业务模式的场景差异，而非机械对半凑数 |

## 课件页要点

1. 讲解案例时，重点带出"可复制规律"这一栏，避免案例讲解流于故事分享而没有提炼出可执行的方法论。
2. 可结合具体行业让参训企业员工联想自己是否有类似的成功经历，作为共创阶段自行补充案例的引导示范。
3. 强调案例中反复出现的"耐心""坦诚""不虚张声势"等主题，这些是贯穿多个案例的隐性共性，可以作为课程小结的呼应点。
