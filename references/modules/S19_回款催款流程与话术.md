# S19 回款催款流程与话术

> 版本：v1.0（正式稿）
> 篇章：十一、售后服务篇
> 模板类型：混合（类型D2逾期阶梯 + 类型A催款话术）
> 适用业务模式：甲乙差异明显
> 前置依赖：S10（账期让步结果是催款节奏的基准）、S04（分层影响催收方式）、S03（信用风险判定与本模块联动）
> 模块目的：让催收有专业、标准的方式，既保住回款又不破坏客户关系

---

## 一、逾期阶梯（D2，以约定付款日为基准）

| 编号 | 阶梯层级 | 触发条件 | 处理方式 | 审批权限 |
|---|---|---|---|---|
| S19-01 | L0 到期提醒 | 约定付款日前3天 | 友好提醒，非催收性质 | 一线人员自主 |
| S19-02 | L1 轻度逾期 | 逾期1-7天 | 委婉提醒，了解延迟原因 | 一线人员自主 |
| S19-03 | L2 中度逾期 | 逾期8-30天 | 正式催款沟通，明确后续影响（如暂停后续供货，见第四节） | 主管介入 |
| S19-04 | L3 重度逾期 | 逾期31-60天 | 书面催款函，评估是否暂停合作关系 | 主管+财务共同决策 |
| S19-05 | L4 严重逾期 | 逾期60天以上 | 法务介入，评估仲裁/诉讼可能性 | 公司高层+法务 |

**说明**：以上以甲的常规账期（如30天）为参照设计；乙涉及S10账期让步（如S10-07分期付款方案）的客户，逾期阶梯应以**该客户实际约定的账期**为基准起算，而非公司默认账期，避免误将已获批准延期的客户当作逾期处理。

## 二、客户分层对催款方式的影响（新增，兑现分层依赖关系）

不同分层客户在逾期处理的**语气柔性和升级速度**上应有差异，但**不代表分层越高越可以纵容拖欠**：

| 客户分层 | 处理方式调整 |
|---|---|
| S/A类 | L1-L2阶段可保持更柔性的沟通语气，适度延长给予书面还款计划的宽限期（如L2阶段的正式沟通可比标准流程晚3-5天启动）；**但若给予柔性空间后仍不履约（如约定的还款计划到期仍未支付）**，应比标准流程更快地升级至L3甚至跳过部分中间阶段，避免因分层高就无限纵容，导致大客户形成"反正可以拖"的习惯，损害整体回款纪律 |
| B/C类 | 按第一节标准阶梯执行，不额外给予柔性空间，语气和升级节奏保持一致 |

**原则**：分层带来的是"多一次机会"而非"更宽松的最终标准"，一旦柔性处理后仍不履约，问题的严重性判断应比普通客户更审慎（因为高价值客户的拖欠对企业现金流影响更大），而非更宽容。

## 三、真实资金困难 vs 疑似恶意拖延的区分（参照S03/S18已建立逻辑）

| 状态 | 判断标准 | 处理方向 |
|---|---|---|
| 信息不足（暂不定性） | 首次逾期，或逾期原因客户已主动说明且合理（如下游客户回款延迟） | 按常规阶梯友好处理，给予适度理解 |
| 存疑（疑似恶意拖延） | 多次以相似借口拖延、拒绝沟通具体还款计划、或有其他客户反馈类似拖欠行为 | 转交主管评估，考虑暂停后续供货/服务，同步在S04/S03重新评估该客户诚意状态 |

## 四、暂停供货/服务的执行与恢复机制（新增）

催款话术中反复提及"暂停供货/服务"作为施压手段，若无实际执行机制支撑，等同于虚张声势，需明确以下规则：

| 事项 | 说明 |
|---|---|
| 决策权限 | 暂停供货/服务需经主管（L2阶段）或主管+财务共同决策（L3阶段及以上）审批，一线人员不得自行宣布或执行暂停，也不得在未获授权时以"我可以决定暂停"的语气误导客户 |
| 执行操作 | 决策通过后，由财务/订单系统操作人员在系统中标记该客户为"暂停发货/服务"状态，销售/项目负责人需同步知晓，避免出现审批已暂停但一线仍在正常接单的执行脱节 |
| 恢复条件 | 客户结清全部逾期金额后即可恢复正常供货/服务；若客户仅部分结清，需同时提供后续欠款的书面还款计划并经主管确认后，方可考虑恢复，且恢复后的合作条款可评估是否调整为更严格的付款方式（如改为预付款或缩短账期），而非自动恢复至原条款 |
| 恢复决策权限 | 与暂停决策权限一致，需原审批人员或更高层级确认后方可恢复，不由一线人员自行判断恢复 |

## 五、部分付款情况的处理

| 情况 | 处理方式 |
|---|---|
| 客户支付部分金额，承诺后续补齐 | 确认书面还款计划（具体金额+日期），按新计划的到期日重新计入逾期阶梯，而非视为已解决 |
| 客户多次部分付款但始终未结清 | 参照"疑似恶意拖延"路径评估，同时考虑是否暂停新增订单直至结清（参照第四节执行机制） |

## 六、案例公司甲催款话术

**S19-06｜L1轻度逾期提醒**

| 字段 | 内容 |
|---|---|
| 编号 | S19-06 |
| 对话对象角色 | 采购经理/财务对接人 |
| 场景/触发条件 | 付款逾期1-7天 |
| 标准话术 | "您好，看到这笔货款的付款日期已经过了几天，不知道是不是走款流程上有些延迟？方便的话麻烦确认一下大概什么时候能到账。" |
| 禁忌话术 | 不要一上来就用警告性语气（如"再不付款就要停止供货"），轻度逾期通常是流程延迟而非恶意，语气过重容易损害关系 |
| 话术意图（四维度） | **情绪**：保持轻松、理解的语气，避免让客户觉得被指责；**信息目标**：了解延迟原因，判断是流程性延迟还是其他问题；**关系**：维护正常合作关系，不因短期逾期就显得不信任客户；**行动导向**：获得具体的到账时间承诺 |
| 升级路径 | 若客户明确给出合理时间且按期到账：结束此轮催收；若逾期超过7天仍无回应或反复拖延：升级至S19-07对应话术 |
| 使用注意 | 语气应友好，避免使用"催款"字眼，用"确认到账时间"这类中性表述 |

**S19-07｜L2中度逾期正式沟通**

| 字段 | 内容 |
|---|---|
| 编号 | S19-07 |
| 对话对象角色 | 采购经理/财务对接人 |
| 场景/触发条件 | 付款逾期8-30天 |
| 标准话术 | "这笔款项目前已经逾期XX天了，我们这边也需要向公司汇报回款情况。麻烦您这边明确一下具体的付款计划，如果这周内无法处理，可能会影响我们后续的供货安排（参照第四节暂停供货执行机制）。" |
| 禁忌话术 | 不要用威胁性但不会真正执行的话（如从未真正暂停供货却反复用这句话施压，会失去可信度）；不要在此阶段就直接转法务字眼，程度不匹配 |
| 话术意图（四维度） | **情绪**：语气比L1更正式、更强调紧迫性，但仍保持专业而非对抗；**信息目标**：获得具体、可执行的还款计划而非模糊承诺；**关系**：明确后果但留有合作空间，非彻底翻脸；**行动导向**：促成书面还款计划确认 |
| 升级路径 | 若客户提供还款计划并部分执行：参照第五节部分付款处理；若客户回避或拒绝沟通：转交主管，进入S19-08书面催款函 |
| 使用注意 | 提及的后果（暂停供货）必须是真实会执行的，且需确认第四节的审批流程已启动或即将启动，不能虚张声势 |

## 七、案例公司乙催款话术

**S19-08｜L3重度逾期书面催款函要点**

| 字段 | 内容 |
|---|---|
| 编号 | S19-08 |
| 对话对象角色 | 财务/分管领导 |
| 场景/触发条件 | 付款逾期31-60天（以实际约定账期为基准） |
| 标准话术 | 书面函件核心要点："根据合同约定，贵方应于[日期]前完成付款，目前已逾期[X]天。我方已多次友好沟通，现正式书面提醒，如在[具体日期]前仍未完成付款，我方将根据合同条款评估暂停后续服务及采取进一步措施的必要性。" |
| 禁忌话术 | 不要在书面函件中使用情绪化或威胁性过重的措辞，应基于合同条款客观陈述；不要省略具体的合同依据和时间节点 |
| 话术意图（四维度） | **情绪**：以正式、客观的书面形式传递严肃性，不含个人情绪色彩；**信息目标**：留存书面证据，为后续可能的法律程序做准备；**关系**：仍保留合作可能性的措辞（"评估必要性"而非"必然终止"），不完全关闭沟通空间；**行动导向**：促使客户给予正式回应或安排更高层面沟通 |
| 升级路径 | 若客户回应并安排还款：参照第五节部分付款处理或结束催收；若无回应或明确拒绝：转入S19-05法务介入 |
| 使用注意 | 书面函件需经内部法务或主管审核后发出，不由一线人员自行拟定发送 |

## 八、本模块专属验收细则

| 检查点 | 标准 |
|---|---|
| 阶梯层级清晰 | 是否给出具体逾期天数区间和对应处理方式、审批权限 |
| 账期基准准确 | 是否说明以实际约定账期（含S10让步结果）为基准，而非公司默认账期 |
| 分层影响是否兑现 | 是否说明不同分层在语气柔性和升级速度上的具体差异，而非只声明依赖关系未实际体现 |
| 恶意与真实困难区分 | 是否给出具体判断标准，而非笼统评估 |
| 暂停供货机制是否完整 | 是否说明决策权限、执行操作、恢复条件，而非仅将"暂停供货"作为口头施压手段 |
| 部分付款处理存在 | 是否说明部分付款后如何重新计入阶梯，而非视为问题已解决 |
| 话术语气递进合理 | 各阶梯话术语气是否随严重程度递进，且不虚张声势 |
| 编号完整 | 每条话术/阶梯是否有唯一编号 |

## 九、课件页要点

1. 强调催款语气应随逾期程度递进，避免一开始就用最严厉的措辞，也避免长期逾期还用轻描淡写的语气。
2. 讲解客户分层对催款方式的影响——高价值客户可以多一次机会，但绝不是可以无限纵容，柔性处理后仍不履约应更快升级。
3. 讲解暂停供货/服务的完整执行与恢复机制，让学员理解这不是一句口头威胁，而是有真实的审批、执行、恢复流程支撑。
4. 讲解如何区分真实资金困难与疑似恶意拖延，避免一刀切对待所有逾期客户。
5. 现场练习：给学员几个不同逾期阶段和不同分层的模拟场景，让其选择合适的话术、处理方式，并判断是否需要启动暂停供货机制。
