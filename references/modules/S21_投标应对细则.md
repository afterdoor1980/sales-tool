# S21 投标应对细则

> 版本：v1.0（正式稿）
> 篇章：十二、竞争应对篇
> 模板类型：混合（类型C1投标流程 + 类型C2废标风险清单 + 类型A评标应答话术）
> 适用业务模式：仅乙（甲无招投标场景）
> 前置依赖：S05（招标办/评审专家角色）、S09（技术方案内容复用）、S10（报价阶梯）、S13（中标后转入合同签订，电子招投标可参照S13电子签约先例）、S20（同台竞标的竞品对比）
> 模块目的：在招投标场景中有章法应对，不因流程生疏而错失中标机会

---

## 一、与S09的边界说明

S21标书中的技术方案**内容上复用S09方案设计的产出**，但**格式和合规要求不同**——标书需严格按招标文件的格式、章节顺序、盖章要求编排，不能直接把S09的方案文档原样提交，需要专人按标书规范重新排版整合。

## 二、投标流程

| 编号 | 步骤序号 | 具体动作 | 责任人/角色 | 产出物/检查点 |
|---|---|---|---|---|
| S21-01 | 1 | 获取招标文件后，先判断项目匹配度和资质要求（参照S03），明显不符合则及时放弃，避免浪费投标资源；同时参照第五节评估是否存在陪标信号，决定投入资源程度 | 商务负责人 | 参投/放弃决策记录，含资源投入程度判断 |
| S21-02 | 2 | 组建投标小组，明确分工（技术标编制人、商务标编制人、法务合规审核人） | 项目负责人 | 分工确认表 |
| S21-03 | 3 | 资质材料准备与核验，确保证书有效期和招标文件要求匹配 | 商务负责人 | 资质清单核验记录。**若未通过**：评估能否短期内补齐，无法补齐则放弃投标，绝不提交不实材料 |
| S21-04 | 4 | 标书编制（技术标复用S09方案，突出案例佐证；商务标报价参照S10阶梯报价预留合理空间） | 技术负责人+商务负责人 | 标书初稿 |
| S21-05 | 5 | 内部标书评审与合规检查（避免格式、报价等废标风险点，参照第三节清单） | 法务/项目负责人 | 评审确认。**若未通过**：退回修改，严禁抱侥幸心理提交有明显瑕疵的标书 |
| S21-06 | 6 | 标书递交（纸质或电子招投标平台，见第七节），确保截止时间前完成 | 商务负责人 | 递交回执 |
| S21-07 | 7 | 开标与澄清应答（如需对标书内容进行澄清说明） | 项目负责人 | 澄清记录 |
| S21-08 | 8 | 评标结果跟进 | 商务负责人 | 结果确认 |
| S21-09 | 9（中标） | 转入S13合同签订流程 | 项目负责人 | — |
| S21-10 | 9（落标） | 转入S24失败案例复盘 | 项目负责人 | 复盘记录 |

## 三、废标风险点清单（类型C2，避免低级失误导致废标）

| 条目名称 | 说明 |
|---|---|
| 格式不符 | 未按招标文件规定的字体、页数、装订方式执行 |
| 密封/标识不当 | 密封条、标书袋标识不符合要求（电子招投标对应加密文件格式/命名规则不符，见第七节） |
| 报价大小写不一致 | 报价的数字和大写金额不一致，或前后文件报价不一致 |
| 签字盖章缺失 | 缺少法定代表人签字、公章或授权委托书（电子招投标对应电子签章/CA证书未正确使用，见第七节） |
| 资质证书过期 | 提交时证书已过有效期 |
| 超时提交 | 未在截止时间前完成递交 |

**责任人**：法务/项目负责人在S21-05评审环节需逐项核对此清单，作为标书提交前的最后一道防线。

## 四、时间紧迫情况的处理

若招标周期短、标书编制时间明显不足，应：
1. 优先评估是否有同类项目的历史标书/方案可快速复用调整，而非从零开始
2. 若时间确实不足以保证标书质量，权衡是否放弃本次投标——仓促提交低质量标书不仅难中标，还可能因此暴露专业度不足，影响客户对企业的长期印象
3. 不因赶时间而跳过S21-05的合规检查环节

## 五、"陪标概率评估"（是否只是充当分母）

有时客户邀请投标只是为了满足"多家比选"的合规形式要求，实际已内定其他供应商。识别信号（参照S03/S05已建立的信息不足/存疑区分逻辑）：

| 信号 | 说明 |
|---|---|
| 招标文件的技术参数高度定制化、明显指向某个特定竞品的规格 | 单项信号 |
| 邀标时间极为仓促，明显不给予充分准备时间 | 单项信号 |
| 招标方对接人态度明显敷衍、不愿深入交流需求 | 单项信号 |

**判断阈值**（新增，避免仅凭感觉判断）：
- 出现以上**1个信号**：判定为"信息不足"，按正常资源投入参与，保持观察
- 出现以上**2个及以上信号**：判定为"存疑（疑似陪标）"，按第九节资源投入建议简化准备投入，但仍参与投标（不建议直接放弃，理由见下）

**处理原则**：即便判定为疑似陪标，也不建议轻易放弃——一是判断可能有误，二是即使这次陪标也是维护客户关系、积累投标经验、进入合格供应商库的机会。但应据此调整资源投入程度（简化准备而非全力以赴），避免在明显希望渺茫的项目上过度消耗资源。

## 六、评标环节应答话术（类型A）

**S21-11｜评标委员会技术质询应答**

| 字段 | 内容 |
|---|---|
| 编号 | S21-11 |
| 对话对象角色 | 评标专家/技术把关人 |
| 场景/触发条件 | 评标会现场，专家对技术方案提出质询 |
| 标准话术 | "您提到的这个问题，我们在方案第X页有详细说明，具体是基于XX现场勘测数据设计的，可以补充说明一下具体的实施细节和过往类似项目的验证情况。" |
| 禁忌话术 | 不要含糊回避质询；不要在没有把握时临场编造技术细节，应如实说明并承诺会后补充书面材料 |
| 话术意图（四维度） | **情绪**：展现专业、从容的应答姿态；**信息目标**：准确回应质询，消除评委疑虑；**关系**：建立评标专家对我方专业度的信任；**行动导向**：获得评委对该项技术方案的认可 |
| 升级路径 | 若当场无法完整回答：承诺会后书面补充说明，不得含糊带过 |
| 使用注意 | 评标现场应答需提前推演可能被质询的高频问题，参照S09方案设计中的技术要点准备 |

**S21-12｜评标委员会商务报价质询应答（新增）**

| 字段 | 内容 |
|---|---|
| 编号 | S21-12 |
| 对话对象角色 | 评标专家/财务评委 |
| 场景/触发条件 | 评标会现场，评委质疑报价明显低于或高于其他投标方，要求说明成本构成合理性 |
| 标准话术 | "我们的报价是基于[具体成本构成，如自有产线降低的制造成本/规模化采购降低的原材料成本]测算的，可以提供成本构成明细供评委参考，确保报价的可持续性和履约能力。" |
| 禁忌话术 | 不要含糊说"我们成本控制得好"而不给具体依据；不要在报价明显偏低时无法自圆其说，这类质疑通常是评委担心低价中标后无法保质履约，需正面消除这层顾虑 |
| 话术意图（四维度） | **情绪**：以专业、坦然的态度回应，消除评委对"低价陷阱"或"高价不合理"的疑虑；**信息目标**：提供具体可信的成本依据；**关系**：建立评委对我方报价可信度和履约能力的信任；**行动导向**：获得评委对报价合理性的认可 |
| 升级路径 | 若评委仍存疑：承诺提供更详细的书面成本核算说明，参照S13合同讲解中全生命周期成本的论证逻辑 |
| 使用注意 | 需提前准备好可自圆其说的成本构成说明，不能临场编造数字 |

**S21-13｜评标委员会资质合规质询应答（新增）**

| 字段 | 内容 |
|---|---|
| 编号 | S21-13 |
| 对话对象角色 | 招标办/评标专家 |
| 场景/触发条件 | 评标会现场，评委对某项资质材料的有效性或完整性提出疑问 |
| 标准话术 | "这份资质材料是[具体说明，如颁发机构、有效期]，如果需要，我们可以现场提供原件核验，或者会后立即补充相关证明文件。" |
| 禁忌话术 | 不要在资质材料确实存在瑕疵时试图蒙混过关或狡辩；如实说明情况比临场狡辩更有利于长期信誉 |
| 话术意图（四维度） | **情绪**：以坦然、配合的态度回应，展现合规意识；**信息目标**：消除评委对资质真实性/有效性的疑虑；**关系**：维护企业合规、诚信的形象；**行动导向**：促成评委认可资质材料的有效性 |
| 升级路径 | 若资质材料确实存在瑕疵（如证书临期）：如实说明情况及补正计划，不掩饰问题；若因此导致废标风险，参照S21-05评审环节本应提前发现此问题，事后应复盘流程漏洞 |
| 使用注意 | 资质材料的有效性核验应在S21-03、S21-05阶段就已完成，评标现场质询理应是走确认流程而非首次发现问题 |

## 七、电子招投标平台补充说明（新增，参照S13电子签约先例）

许多招投标项目现已通过电子招投标平台进行（如上传电子标书、在线开标），与传统纸质投标在操作细节上有所不同：

| 事项 | 说明 |
|---|---|
| 电子标书加密与解密 | 电子标书通常需要在规定时间前完成加密上传，开标时按平台规则在线解密，需提前测试平台操作流程，避免因不熟悉操作导致逾期或解密失败视为无效标 |
| CA证书/电子签章 | 电子招投标通常需要企业数字证书（CA证书）进行电子签章，需提前申请并确认证书在有效期内，避免因证书问题导致无法完成电子签署 |
| 上传格式与大小限制 | 需按平台要求的文件格式（如PDF）和大小限制上传，超出限制或格式不符可能导致上传失败或被判定无效 |
| 网络与时间余量 | 建议预留充分时间余量提前完成上传，避免在截止时间前因网络问题导致提交失败，此类情况通常不被视为可申诉的正当理由 |
| 使用注意 | 电子招投标不改变第二节流程的整体步骤和第三节废标风险点的实质要求，仅是操作形式的差异，仍需按标准流程走完各环节审核 |

## 八、投标合规红线

| 红线 | 说明 |
|---|---|
| 不参与围标、串标 | 不与其他投标方私下协商报价或让标 |
| 不进行商业贿赂 | 不通过财物或其他不正当利益影响评标结果 |
| 不提交虚假材料 | 资质、业绩证明等材料必须真实，不伪造或篡改 |

---

## 九、中标后的责任

中标后若因自身原因无法履约或放弃履约，通常涉及保证金损失及信誉影响，甚至可能被列入不良记录，因此在S21-01阶段的参投/放弃判断应审慎，避免"先中标再考虑能不能做"的侥幸心理。

## 十一、本模块专属验收细则

| 检查点 | 标准 |
|---|---|
| 流程步骤顺序合理 | 是否体现真实先后依赖 |
| 与S09边界清楚 | 是否说明标书技术方案复用S09但格式合规要求不同 |
| 废标风险清单完整 | 是否覆盖格式、密封、报价、签章、资质、时限等高频废标风险点，含电子招投标对应风险点 |
| 时间紧迫处理存在 | 是否说明周期不足时的应对原则 |
| 陪标识别有具体阈值 | 是否给出信号数量对应的判定标准（1个/2个及以上），而非仅凭主观感觉判断 |
| 评标应答覆盖技术/商务/资质三类 | 是否覆盖技术质询、商务报价质询、资质合规质询三种高频评标场景，而非只有技术质询一类 |
| 电子招投标补充是否覆盖 | 是否说明电子招投标平台的操作差异，而非仅默认纸质投标 |
| 合规红线明确 | 是否明确围标串标、商业贿赂、虚假材料等红线 |
| 分层关联体现 | 是否说明不同项目类型的资源投入差异 |

## 十二、课件页要点

1. 强调废标风险清单的重要性——很多标书是败在低级格式失误而非方案质量本身。
2. 讲解陪标信号识别的具体判断阈值，让学员理解如何理性判断资源投入程度，而非盲目全力以赴或轻易放弃。
3. 讲解评标现场三类高频质询（技术/商务/资质）的应答方式，尤其强调资质问题不应在评标现场才首次被发现。
4. 讲解电子招投标平台的操作要点，避免因不熟悉平台操作导致低级失误。
5. 强调合规红线，任何形式的围标串标和商业贿赂都是绝对禁止的。
6. 现场练习：给学员一份模拟招标文件，让其识别其中的废标风险点和潜在陪标信号，并练习技术、商务、资质三类评标质询的应答。
