# S16 转介绍标准话术

> 版本：v1.0（正式稿）
> 篇章：十、跟进与复购篇
> 模板类型：类型A（话术库）
> 适用业务模式：甲乙对比
> 前置依赖：S15（触发条件和时机判断）、S03（新客户质量判定影响激励）
> 模块目的：让销售敢于、也知道怎么开口向客户要转介绍，而不是因为不好意思而放弃这个低成本获客机会

---

## 一、正文

**S16-01｜甲：主动请求转介绍（对应S15-05触发）**

| 字段 | 内容 |
|---|---|
| 编号 | S16-01 |
| 对话对象角色 | 采购经理 |
| 场景/触发条件 | 客户已完成至少2次稳定复购且互动中表现满意（S15-05触发） |
| 标准话术 | "跟您合作这段时间挺顺利的，如果您身边有同行业的朋友也有类似的采购需求，方便的话可以帮忙引荐一下，我们这边也会有一些老客户转介绍的优惠回馈给您。" |
| 禁忌话术 | 不要只谈激励不谈价值（显得功利）；不要在客户刚有一次不太顺畅的合作体验后立即提出，容易适得其反 |
| 话术意图（四维度） | **情绪**：以自然、不强求的语气提出，避免让客户感到有压力；**信息目标**：明确表达转介绍诉求，同时不掩饰有回馈机制；**关系**：基于已建立的信任关系顺势提出，而非突兀开口；**行动导向**：让客户明确表态是否有合适人选可介绍 |
| 升级路径 | 若客户当场答应但后续无下文：参照S16-05跟进话术；若客户婉拒：参照S16-06得体回应 |
| 使用注意 | 提出前需确认客户近期互动确实满意（无未解决的投诉或异议），避免时机不当 |

**S16-02｜乙：主动请求转介绍（对应S15-06触发）**

| 字段 | 内容 |
|---|---|
| 编号 | S16-02 |
| 对话对象角色 | 分管领导或项目对接人 |
| 场景/触发条件 | 项目验收合格且客户满意度高，或双方续签多期合作（S15-06触发） |
| 标准话术 | "这个项目能顺利完成，也感谢贵方团队的配合。如果集团内其他分公司，或者您认识的同行业单位有类似的改造需求，方便的话希望您能帮忙引荐，我们也很乐意为后续合作提供同等的服务保障。" |
| 禁忌话术 | 不要在验收刚完成、细节尚未完全确认时就急于提出，应确保客户满意度真实稳定后再开口；不要暗示"介绍了才有后续保障"这种交换式表述 |
| 话术意图（四维度） | **情绪**：以感谢和肯定合作成果的姿态自然带出诉求；**信息目标**：了解客户所在集团或行业内是否有其他潜在需求线索；**关系**：借助已建立的成功案例强化长期合作关系；**行动导向**：获得具体的引荐线索或明确的"暂无合适对象"回应 |
| 升级路径 | 若对方表示需要考虑：不强求立即答复，可在下次常规联系时礼貌重提一次；若明确表示不便引荐：转为仅请求案例授权（S16-03） |
| 使用注意 | 乙的转介绍往往涉及集团内部关系，不宜像甲一样直接谈物质激励，更适合强调长期合作价值 |

**S16-03｜乙：案例授权请求（区别于转介绍新客户）**

| 字段 | 内容 |
|---|---|
| 编号 | S16-03 |
| 对话对象角色 | 分管领导或市场对接窗口 |
| 场景/触发条件 | 项目验收合格且客户满意，但客户不便直接引荐新客户时的替代请求；或独立于转介绍请求单独提出 |
| 标准话术 | "如果引荐不太方便，我们想请教一下，是否可以将这次合作作为案例在我们的官网或行业材料中做一个简要介绍？内容我们会提前给您过目确认，涉及贵方的具体信息也会先获得同意才会使用。" |
| 禁忌话术 | 不要未经同意直接使用客户名称或项目细节对外宣传；不要在客户明确表示不希望曝光时反复请求 |
| 话术意图（四维度） | **情绪**：以尊重和透明的姿态提出，避免让客户感到信息被擅自使用的风险；**信息目标**：获得可用于市场材料的案例授权；**关系**：即使转介绍不成，也能维持关系并获得阶段性成果；**行动导向**：取得明确的授权范围（如是否可提及企业名称、具体到什么细节程度） |
| 升级路径 | 若客户完全不同意任何形式的案例曝光：礼貌接受，不再重复请求，转为纯粹关系维护 |
| 使用注意 | 涉及政府/国企客户时，案例授权可能需要客户内部走额外审批流程，需给予充分时间，不可催促 |

**S16-04｜通用：客户主动提出转介绍意愿时的即时响应（对应S15规则）**

| 字段 | 内容 |
|---|---|
| 编号 | S16-04 |
| 对话对象角色 | 通用 |
| 场景/触发条件 | 客户未经我方请求，主动表示"我有朋友/同行也需要，我帮你介绍一下" |
| 标准话术 | "太感谢了！方便的话我可以先加一下对方的联系方式，或者您方便的话也可以先帮忙引荐一下，我们会认真对接，也不会给您添麻烦。" |
| 禁忌话术 | 不要反应冷淡或拖延处理（如"好的谢谢，不着急"），错失客户主动示好的热情窗口；不要一次性追问过多细节让客户感到压力 |
| 话术意图（四维度） | **情绪**：以真诚、及时的感谢回应客户的主动善意，趁热打铁；**信息目标**：尽快获取可执行的引荐信息（联系方式或引荐动作）；**关系**：强化客户"主动帮忙"带来的良好互动体验；**行动导向**：促成实际的引荐行动尽快发生，而非停留在口头意愿 |
| 升级路径 | 若客户当场提供了联系方式或引荐动作：按新客户接触流程处理，同步进行S03判定；若客户只是口头表示、未有实际行动：参照S16-05在合理时间后温和跟进 |
| 使用注意 | 应在对话当下就积极回应，不要等事后才想起跟进，避免热情窗口流失 |

**S16-05｜通用：转介绍口头答应但迟迟无下文的跟进**

| 字段 | 内容 |
|---|---|
| 编号 | S16-05 |
| 对话对象角色 | 通用 |
| 场景/触发条件 | 客户此前答应引荐（无论是我方请求后还是客户主动提出），但2-3周内无实际进展 |
| 标准话术 | "之前您提到可能有朋友/同行有类似需求，不知道是否方便的时候还能帮忙引荐一下？不着急，方便的时候麻烦您了。" |
| 禁忌话术 | 不要频繁催促（超过2次追问容易显得强求）；不要在追问中流露出不满或失望情绪 |
| 话术意图（四维度） | **情绪**：以轻松、不施压的方式提醒，而非追债式催促；**信息目标**：了解引荐是否还有可能，或者客户已经改变主意；**关系**：即使最终没有下文，也不损害现有合作关系；**行动导向**：获得明确的进展或"暂时没有合适人选"的回应 |
| 升级路径 | 若追问1-2次后仍无下文：不再追问，视为此次转介绍机会自然结束，按S15触发条件等待下一次合适时机（如满足新一轮触发条件） |
| 使用注意 | 全程保持轻松语气，让客户感到"不追问也没关系"，而非有心理负担 |

**S16-06｜通用：转介绍被婉拒时的得体回应**

| 字段 | 内容 |
|---|---|
| 编号 | S16-06 |
| 对话对象角色 | 通用 |
| 场景/触发条件 | 客户明确表示不方便/不愿意进行转介绍 |
| 标准话术 | "完全理解，这个事儿看缘分，不用有负担。跟您的合作我们已经很满意了，后面有其他能帮到您的地方尽管说。" |
| 禁忌话术 | 不要追问拒绝原因显得纠缠；不要表现出明显的失落情绪影响客户关系；不要因此减少后续常规服务质量 |
| 话术意图（四维度） | **情绪**：让客户感到被拒绝也完全没有负担，维护轻松的关系氛围；**信息目标**：无（此环节以关系维护为主，不追求进一步信息）；**关系**：确保被拒绝不影响后续合作关系和服务质量；**行动导向**：自然过渡回常规关系维护，不留尴尬 |
| 升级路径 | 参照S15规则，至少间隔6个月（甲）或下一个项目节点（乙）才可再次提出，不在短期内重复请求 |
| 使用注意 | 拒绝后的服务质量不应有任何降低，避免客户感到"不介绍就区别对待" |

## 二、通用执行规则（实操层面容易被忽略的细节）

| 规则 | 说明 |
|---|---|
| 接触新客户前的身份确认 | 接触转介绍来的新客户前，需先与老客户确认是否可以在新客户面前提及其姓名/身份，未经确认不得擅自透露，避免让老客户感到被"代言"而不适；确认可以提及后，开场时自然提及可增强新客户信任度（如"是XX介绍我联系您的"），但若老客户明确表示不便提及，则改用"经业内朋友推荐"等模糊表述 |
| 转介绍来源标记 | 每一位经转介绍渠道接触的新客户，需在客户档案/CRM记录中标记转介绍来源（老客户姓名/编号），作为S15转介绍激励机制执行的依据，避免激励发放无据可查；此项由接洽该新客户的销售/项目负责人在首次接触后及时完成，不得事后补记造成遗漏 |

## 三、本模块专属验收细则

| 检查点 | 标准 |
|---|---|
| 覆盖场景完整 | 是否覆盖主动请求、客户主动提出、口头答应无下文、被婉拒这几种高频场景，不能只有"如何开口"一种 |
| 甲乙差异体现 | 乙是否体现不直接谈物质激励、更强调长期合作价值的差异 |
| 案例授权与转介绍区分清楚 | 是否说明案例授权和转介绍新客户是两种不同的请求，不能混为一谈 |
| 身份确认规则是否存在 | 是否说明接触新客户前需与老客户确认身份透露范围，而非擅自代言 |
| 来源标记规则是否存在 | 是否说明需标记转介绍来源以支撑S15激励机制执行 |
| 话术意图四维度完整 | 情绪、信息目标、关系、行动导向四项均需填写 |
| 升级路径明确 | 每条话术是否说明后续场景该怎么处理 |
| 编号完整 | 每条话术是否有唯一编号 |

## 四、课件页要点

1. 强调"转介绍不是难以启齿的事"，用自然、不功利的方式提出，比生硬地谈激励更容易成功。
2. 讲解客户主动提出转介绍时要"趁热打铁"及时响应，而不是被动等待。
3. 讲解被婉拒后的得体回应，避免因一次拒绝影响长期合作关系。
4. 讲解接触新客户前的身份确认规则和来源标记习惯，这两点看似琐碎但直接影响客户关系维护和激励机制的可执行性。
5. 现场练习：让学员分别练习主动请求、响应客户主动提出、跟进无下文、处理婉拒这四种场景的话术，并模拟一次接触转介绍新客户时如何自然提及来源。
