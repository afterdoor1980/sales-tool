# S13 合同讲解与签订要点

> 版本：v1.0（正式稿）
> 篇章：九、成交篇
> 模板类型：混合（类型C1签约流程 + 类型A条款讲解话术）
> 适用业务模式：甲乙差异明显（乙的合同复杂度和签署流程远高于甲）
> 前置依赖：S12（购买信号确认后进入本模块）、S10（价格条款需与阶梯报价一致）、S11（条款异议可关联对应话术）
> 模块目的：让客户在签约环节理解清楚条款、打消最后顾虑，减少签约后纠纷

---

## 一、合同条款底线原则（新增，重要前提）

与S10阶梯报价的"底线"逻辑一致，合同条款中部分内容属于**不可无限让步的底线**，需在讲解和协商条款前明确：

| 条款类型 | 底线说明 |
|---|---|
| 违约责任基本框架 | 可协商具体赔偿数额、响应时限等细节，但"违约需承担相应责任"这一基本框架不可取消，不能因客户要求而删除违约责任条款本身 |
| 质保范围基本框架 | 可协商质保期长短、覆盖范围细节，但不可承诺"无限期质保"或超出公司实际服务能力的保障承诺 |
| 付款安全机制 | 可协商账期长短、分期方式，但涉及基本的付款保障机制（如预付款比例下限）通常不可完全取消 |

**客户坚持要求突破底线时的处理方式**：不得在谈判现场自行让步突破底线。应先说明"这类条款涉及公司统一标准，需要内部评估"，随后：① 评估该条款修改是否会对公司造成重大风险敞口，若风险过高，可考虑放弃该笔合作，而非勉强签署埋下隐患；② 若客户价值较高（参照S04分层）、确有特殊情况，转交公司高层评估是否给予一次性特批，而非由销售或项目负责人自行拍板。

## 二、案例公司甲 签约流程

**耗时预期**：甲的合同相对标准化，通常当场或1-2天内即可完成签署，无需法务专门审核。

| 编号 | 步骤序号 | 具体动作 | 责任人/角色 | 产出物/检查点 |
|---|---|---|---|---|
| S13-01 | 1 | 确认最终报价、数量、交期已与S10阶梯报价结果一致 | 拜访销售 | 合同条款与最终商定条件完全对应，无遗漏或出入 |
| S13-02 | 2 | 讲解合同关键条款（价格、交期、验收标准、付款方式、违约责任） | 拜访销售 | 客户对各条款均已理解，无遗留疑问 |
| S13-03 | 3 | 处理客户对条款提出的具体疑问或异议 | 拜访销售 | 疑问已解答，或明确转入S11对应异议处理流程。**若未通过**：客户异议无法当场解决，不得强行推进签约，应记录异议内容，转交主管评估是否需要调整条款或走特批流程；**若客户要求突破条款底线**：参照第一节底线原则处理，不得自行让步 |
| S13-04 | 4 | 客户确认签署（纸质或电子签约，见第五节） | 拜访销售/客户 | 双方完成签署的正式合同 |

## 三、案例公司乙 签约流程

**耗时预期**：乙的合同通常需要法务审核，涉及多方会签，从合同定稿到最终签署可能需要1-3周，销售应提前向客户说明这一周期，避免误以为讲解完当场就能签。

| 编号 | 步骤序号 | 具体动作 | 责任人/角色 | 产出物/检查点 |
|---|---|---|---|---|
| S13-05 | 1 | 确认合同商务条款（价格、付款节奏、服务范围）与S09方案、S10阶梯报价结果一致 | 项目负责人 | 合同商务条款无遗漏或出入 |
| S13-06 | 2 | 提交己方法务审核，同时告知客户己方合同可能需要客户法务同步审核 | 项目负责人/公司法务 | 法务审核意见，明确是否需要调整条款。**若未通过**：法务提出修改意见，退回商务条款重新协商，不得跳过法务意见强行推进 |
| S13-07 | 3 | 讲解合同关键条款给客户相关角色（技术把关人关注验收标准、财务关注付款条款、分管领导关注责任与保障条款） | 项目负责人 | 各角色对应条款疑问已解答 |
| S13-08 | 4 | 处理双方法务或客户各角色提出的条款异议、协调修改 | 项目负责人 | 异议已解决并达成一致文本。**若未通过**：多轮协商仍无法达成一致的条款，需评估该条款是否为交易的实质性障碍，若是则升级至公司高层参与谈判，若非实质性障碍可考虑妥协处理；**若客户要求突破条款底线**：参照第一节底线原则处理 |
| S13-09 | 5 | 走双方内部用印/会签流程（纸质或电子签约，见第五节） | 项目负责人协调 | 双方完成签署的正式合同 |

**审核周期超预期的处理**：若条款反复修改导致实际耗时明显超出预期周期（如超过预期周期50%以上仍未定稿），项目负责人应：① 主动向客户说明当前进展和延误原因，避免客户因流程无声拖延而产生疑虑或转向竞品；② 内部升级评估卡点具体原因（是法务标准过严、还是客户方要求过多变更），必要时请公司高层介入协调，而非任由流程无限期拖延。

## 四、高频条款讲解话术（类型A）

**S13-10｜付款条款讲解（甲）**

| 字段 | 内容 |
|---|---|
| 编号 | S13-10 |
| 对话对象角色 | 采购经理 |
| 场景/触发条件 | 讲解合同付款方式条款环节 |
| 标准话术 | "付款方式是首批货到验收后30天内付款，后续批次按月结算。这样安排既能让您有时间验收确认质量，也能保证我们这边生产的正常周转，双方都比较稳妥。" |
| 禁忌话术 | 不要在客户还没问之前就主动提出"可以再商量付款方式"，暗示条款有很大弹性空间；不要用专业术语堆砌（如直接说"账期30天"而不解释具体计算起点），造成理解偏差 |
| 话术意图（四维度） | **情绪**：让客户感到付款安排合理、双方对等，而非单方面要求；**信息目标**：确保客户准确理解付款起算时间点和方式，避免后续争议；**关系**：体现互相信任的合作姿态；**行动导向**：让客户明确认可该条款，无遗留疑问 |
| 升级路径 | 若客户要求延长账期：参照S10阶梯报价中账期相关的让步权限（如涉及）评估是否可调整，超出权限需转交主管；若客户要求突破付款安全机制底线：参照第一节底线原则 |
| 使用注意 | 需明确说明"验收后"这一起算点的具体定义，避免后续对"验收完成时间"产生分歧 |

**S13-11｜验收标准条款讲解（乙，技术把关人）**

| 字段 | 内容 |
|---|---|
| 编号 | S13-11 |
| 对话对象角色 | 技术把关人 |
| 场景/触发条件 | 讲解合同中验收标准与流程条款 |
| 标准话术 | "验收标准这块，我们列了具体的技术参数指标和验收流程步骤，包括初验和终验两个阶段。您可以对照现场勘测时确认的需求逐项核对，如果有任何指标需要调整，我们现在就可以一起明确下来，避免后续验收时产生分歧。" |
| 禁忌话术 | 不要用模糊表述如"验收合格即可"而不列明具体指标，容易在后续验收环节产生争议 |
| 话术意图（四维度） | **情绪**：让技术把关人感到验收标准清晰、公平，双方后续不会因标准模糊产生纠纷；**信息目标**：确保验收指标与实际需求完全对应，消除理解偏差；**关系**：以严谨专业的态度建立长期信任；**行动导向**：促成双方对验收标准条款达成逐项明确一致 |
| 升级路径 | 若技术把关人对某项指标有异议：现场协商调整，若涉及重大技术方案变更需转回S09重新评估 |
| 使用注意 | 需提前准备好与S09方案中技术参数完全对应的验收指标清单，避免临场现改造成前后不一致 |

**S13-12｜违约责任条款讲解（乙，分管领导）**

| 字段 | 内容 |
|---|---|
| 编号 | S13-12 |
| 对话对象角色 | 分管领导 |
| 场景/触发条件 | 讲解合同违约责任与保障条款 |
| 标准话术 | "违约责任这部分，我们明确了质保期内的免费维修范围和响应时限，如果因为我方原因造成的问题，会按合同约定承担相应赔偿责任。这部分条款是双向的，同样也约定了贵方在配合条件（如现场配合、付款节点）上的责任。" |
| 禁忌话术 | 不要回避谈论违约责任，含糊带过反而会让分管领导更不放心；不要口头承诺条款之外的额外保障，一切以书面条款为准 |
| 话术意图（四维度） | **情绪**：让分管领导感到责任划分清晰、双向对等，降低决策风险感知；**信息目标**：确保对方准确理解违约情形的认定和赔偿方式；**关系**：体现专业、负责任的合作态度；**行动导向**：消除分管领导对"出问题谁负责"的顾虑，促成签署 |
| 升级路径 | 若分管领导对责任条款要求进一步加强保障（如提高赔偿上限）：评估是否在公司可接受范围内，超出常规范围需转交公司高层决策；若要求取消违约责任框架本身：参照第一节底线原则，不予让步 |
| 使用注意 | 需如实说明条款内容，不夸大保障范围，避免后续无法兑现引发更大纠纷 |

## 五、电子签约场景补充

甲类中小企业间合作现在常用电子签约平台（如法大大、e签宝等），与传统纸质签约在细节上有所不同：

| 事项 | 说明 |
|---|---|
| 适用场景 | 甲类客户较常用电子签约，尤其异地合作或希望加快签约速度时；乙类客户因涉及法务/多方会签，更多仍采用纸质签约+正式用印流程，但部分环节（如意向确认书）也可能采用电子签 |
| 身份认证 | 电子签约前需确认签署方的企业身份认证已完成（如通过营业执照、法人身份信息核验），避免因认证未完成导致签署延误 |
| 签署顺序设置 | 若涉及多方签署，需在平台上正确设置签署顺序（如先客户后我方，或同步签署），避免顺序错误导致合同状态混乱 |
| 电子签约的法律效力说明 | 若客户对电子签约的法律效力存有疑虑，可说明其符合《电子签名法》相关规定，与纸质签约具有同等法律效力，必要时提供平台的资质证明 |
| 使用注意 | 电子签约不改变第一节"合同条款底线原则"和条款讲解的要求，仅是签署形式的差异，讲解环节仍需按第四节话术执行 |

## 六、本模块专属验收细则

| 检查点 | 标准 |
|---|---|
| 签约流程步骤顺序合理 | 是否体现真实先后依赖（如法务审核先于最终签署） |
| 每步责任人明确 | 是否清楚谁负责 |
| 未通过情形有应对 | 法务/条款异议未通过时是否说明具体处理方式，而非只有"确认"字样 |
| 条款底线是否明确 | 是否说明哪些条款不可无限让步，客户坚持突破底线时如何处理 |
| 审核周期超预期是否有应对 | 是否说明审核周期大幅超出预期时该如何处理，而非任由流程无声拖延 |
| 条款讲解话术完整 | 是否含话术意图四维度和升级路径 |
| 耗时预期是否说明 | 是否给出甲乙各自大致的签约周期 |
| 电子签约场景是否覆盖 | 是否说明电子签约的适用场景和注意事项，而非仅默认纸质签约 |
| 甲乙差异体现 | 是否体现乙的法务审核、多方会签等甲不需要的复杂环节 |

## 七、课件页要点

1. 强调条款讲解要"讲清楚而非一带而过"，尤其付款、验收、违约这几类高频引发纠纷的条款。
2. 讲解合同条款底线原则，让学员理解不是所有条款都可以商量，明确哪些是可协商细节、哪些是不可动摇的框架。
3. 讲解乙的法务审核和多方会签流程，让学员理解签约不是讲完就能当场完成，需要合理管理客户预期；同时讲解审核周期超预期时该如何主动沟通而非被动拖延。
4. 讲解电子签约的适用场景和操作要点，尤其甲类客户场景。
5. 现场练习：给学员一份模拟合同条款，让其练习讲解并处理一个模拟异议（含一个触及条款底线的异议），导师用验收细则点评。
