# S27 客户百问百答

> 版本：v1.0（正式稿）
> 模块编号：S27
> 适用业务模式：甲乙通用（涉及业务模式差异的问答分列）
> 适用客户分层：不区分
> 模板类型：类型F（问答库类）
> 溯源：新增模块，结构参考外部《销售手册规范文件（架构篇）》"问答库类"；内容基于案例公司甲（标准化耗材）、乙（定制化方案）设定，口径全部对齐既有正文模块

---

## 定位与使用说明

FAQ 面向**一线快速上岗与统一口径**：新人对客户高频问题不至于答错或口径不一，资深销售遇到少见问题也有基准可循。它**不从零自创答案**，一律从既有正文模块正派口径——所以本模块多数条目都标注了"关联模块"，改动正文时须同步检查本模块口径是否失效。

本模块**不追求穷举所有问题**，只覆盖代表性/高频提问以固化统一口径；实战中遇到的新高频问题按第四节"维护规则"持续增补。涉及红线的回答（合同、合规、付款安全）以正文红线为准，**不得在问答中放开承诺**。

## 一、价格与报价

### 1.1 "你们价格比 XX 厂贵"（甲 · 采购经理）

| 项 | 内容 |
|---|---|
| 典型问题 | "你们这个价也太贵了，XX 厂比你便宜 15%" |
| 统一口径（照读） | "理解您要控制成本。我们这个价格里包含了每批次的质检报告和 72 小时紧急补货承诺——如果按单价对比，XX 厂能做到吗？我们可以看看您的采购量，能不能通过年度框架协议锁定更优价格。" |
| 边界/禁忌 | 不说"我们价格已经是最低了"；不主动大幅让价 |
| 关联模块 | S11-01（价格类·甲·采购经理） |

### 1.2 "采购量大能不能再优惠"（甲）

| 项 | 内容 |
|---|---|
| 典型问题 | "我们一个月这个量，你给个更实惠的价才行" |
| 统一口径（照读） | "量大的话我们可以走年度框架协议，把价格按量级分档锁定，我按您的月度用量帮您算一档合适的。" |
| 边界/禁忌 | 具体让价幅度按 S10 阶梯执行，不现场拍板一个随意数字 |
| 关联模块 | S10（阶梯报价与让步节奏表）、S04（分层封顶） |

## 二、交期与供货

### 2.1 "多久能发货"（甲）

| 项 | 内容 |
|---|---|
| 典型问题 | "现在下单，多久能到货" |
| 统一口径（照读） | "常规品现货、短周期可发；急单我们有 72 小时紧急补货承诺，您把交期要求说一下，我帮您确认库存和排期。" |
| 边界/禁忌 | 不承诺做不到的加急时限；急单涉及额外成本时如实说明 |
| 关联模块 | S11-01（72小时补货承诺）、S09（方案/交期） |

## 三、质量与质保

### 3.1 "质量出问题怎么办"（甲）

| 项 | 内容 |
|---|---|
| 典型问题 | "要是有质量问题，你们负责吗？怎么退换" |
| 统一口径（照读） | "每批次都带质检报告，标准范围内的问题按我们的质保条款处理：该退退、该换换，我帮您走售后流程，不会让您来回扯皮。" |
| 边界/禁忌 | 不承诺"无限期质保"或超出服务能力的保障（合同底线） |
| 关联模块 | S17（服务标准流程）、S13（质保范围·红线型） |

### 3.2 "你们质量跟 XX 比怎么样"（甲）

| 项 | 内容 |
|---|---|
| 典型问题 | "你们和 XX 比，质量到底差在哪" |
| 统一口径（照读） | "我不空口比较，给您两份东西：一是我们的批次质检报告，二是一个我们长期客户用同样品类的真实反馈，您看数据说话。" |
| 边界/禁忌 | 客观对比、不贬低对手；可引用共赢客户案例 |
| 关联模块 | S20（竞品对比话术） |

## 四、方案与资质（乙）

### 4.1 "你们做过类似项目吗"（乙）

| 项 | 内容 |
|---|---|
| 典型问题 | "你们在类似产线改造上有过案例吗？" |
| 统一口径（照读） | "有。我可以给您看同行业/同场景的项目案例和验收结果，既讲成规模的成功案例，也把过程中我们踩过的坑和怎么解决讲清楚，您自己判断匹配度。" |
| 边界/禁忌 | 用真实可核对的案例，不做无法验证的夸大 |
| 关联模块 | S23（成功案例）、S24（失败复盘） |

### 4.2 "你们有哪些资质/合规是齐全的吗"（乙 · 招标）

| 项 | 内容 |
|---|---|
| 典型问题 | "投标要的资质你们都齐全吗？" |
| 统一口径（照读） | "资质这块我们列一份清单给您对照招标要求，缺什么、能不能办、周期多久，我们按要求逐条对，不在资质上替您打没把握的包票。" |
| 边界/禁忌 | 不虚报资质；涉及招投标合规（商业贿赂等红线）一律不碰 |
| 关联模块 | S21（投标应对细则）、S09（方案设计） |

## 五、付款与合同

### 5.1 "能不能晚点付 / 分期"（甲/乙）

| 项 | 内容 |
|---|---|
| 典型问题 | "这笔款能不能晚两个月？" |
| 统一口径（照读） | "账期和分期我们可以谈，我按咱们的合作情况帮您确认一下可行方案，但不能绕过公司的付款底线。" |
| 边界/禁忌 | 不随意承诺超长账期；付款安全机制（预付款下限）为红线，不放开 |
| 关联模块 | S19（回款催款）、S13（付款安全机制·红线型） |

### 5.2 "合同这条能不能改一下"（通用）

| 项 | 内容 |
|---|---|
| 典型问题 | "违约那一条能不能删掉？" |
| 统一口径（照读） | "这类条款是我们公司的统一标准，我不能在谈判现场给您承诺改，需要内部评估。我可以把您的要求带回去，结果尽快给您。" |
| 边界/禁忌 | 违约责任基本框架、质保范围、付款安全机制三条为红线，现场不自行让步 |
| 关联模块 | S13（合同签订要点·红线型） |

## 六、合作与长期服务

### 6.1 "后面有问题找谁"（通用）

| 项 | 内容 |
|---|---|
| 典型问题 | "签了之后出问题我找谁？" |
| 统一口径（照读） | "您下单后我会给您对接一位固定的售后负责人，也把我的联系方式留给您，日常补货、技术问题都能找到人。" |
| 边界/禁忌 | 明确责任人，不留"你去找谁我不知道"的模糊空间 |
| 关联模块 | S17（服务标准流程）、S16（转介绍）

### 6.2 "用得好想推荐给同行"（通用）

| 项 | 内容 |
|---|---|
| 典型问题 | "我一个朋友可能也需要，回头介绍给你？" |
| 统一口径（照读） | "太好了，欢迎。您把贵司的使用数据或验收结果给他看最有说服力，我去拜访时也可以说是您介绍的，走个转介绍。" |
| 边界/禁忌 | 转介绍讲究时机，不在客户尚未满意时强行开口 |
| 关联模块 | S16（转介绍话术）、S15（转介绍触发条件） |

## 七、维护规则

1. **持续增补**：实战中遇到新高频问题，按分类维度补入，不为补而补。
2. **口径对齐**：新增/修改任何问答，必须与对应正文模块当前口径一致；正文改动后，本模块对应条目视为需复核，避免口径漂移。
3. **红线不容许**：凡涉及合同底线、合规、付款安全的问题，回答不得突破正文红线，也不得在本模块自创比正文宽松的口径。
4. **跨业务模式**：同一问题在甲（标准化/比价）与乙（定制化/资质）口径不同时，分列两条，不合并模糊处理。
