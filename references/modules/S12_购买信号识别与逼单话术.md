# S12 购买信号识别与逼单话术

> 版本：v1.0（正式稿）
> 篇章：九、成交篇
> 模板类型：类型A（话术库）
> 适用业务模式：甲乙对比
> 前置依赖：S04（客户分层影响逼单力度）、S05（角色关注点影响逼单话术设计）、S10（价格相关逼单需衔接阶梯报价权限）、S03（诚意判定交叉验证）
> 模块目的：让销售能识别客户准备购买的信号并适时推进成交，避免因不敢逼单错失时机，也避免逼单过猛引起反感

---

## 一、购买信号识别指南（正式逼单前必读）

### 常见真实信号 vs 易误判信号对照表

| 客户表现 | 可能含义 | 判断要点 |
|---|---|---|
| 主动询问交付细节（交期、安装、售后） | 大概率是真实购买信号，客户在为使用做准备 | 若同时伴随具体时间要求（"能不能这个月到货"），信号强度更高 |
| 主动提及内部审批/决策流程节点 | 可能是真实信号（客户在推进内部流程），也可能只是说明还需要走流程、暂缓成交 | 需结合是否已提出具体时间表判断，光说"要走流程"不代表马上能成交 |
| 反复确认价格/条款细节 | 可能是购买信号（在确认最终条件），也可能是习惯性比价、并无实际购买意向 | 参照S03客户诚意判定维度交叉验证，避免把"疑似比价"客户的反复确认误判为购买信号 |
| 询问同类客户案例/评价 | 通常是购买前的最后确认动作，信号较强 | 结合此前沟通阶段判断，若方案讲解刚开始就问这个，可能只是了解阶段，非临近成交 |

**核心原则**：单一信号不足以确认购买意向，应结合至少两个信号同时出现、且客户此前已通过S03门槛判定为真实合作意向（而非疑似比价/陪标客户），才适合正式推进逼单动作。

## 二、案例公司甲（采购经理）

**S12-01｜信号：主动询问具体交付细节**

| 字段 | 内容 |
|---|---|
| 编号 | S12-01 |
| 对话对象角色 | 采购经理 |
| 场景/触发条件 | 客户主动问"最快什么时候能到货""起订量多少可以按这个价格" |
| 标准话术 | "如果我们现在就把具体交期和数量确认下来，我可以马上帮您安排排产，确保在您需要的时间点前完成入库。方便我现在就给您出正式的订单确认吗？" |
| 禁忌话术 | 不要在客户只是随口问问、还没有明确意向时就急于拿出合同，容易显得急躁；不要用"现在不定就没有这个价了"这种施压性话术，除非确实有真实的价格/库存时效限制 |
| 话术意图（四维度） | **情绪**：把客户的"了解性提问"顺势转化为"进入实质推进"的自然过渡，而非生硬转折；**信息目标**：确认客户是否真的准备好进入订单环节；**关系**：不因逼单显得急功近利，保持专业稳重；**行动导向**：推动客户明确给出订单确认或具体顾虑 |
| 升级路径 | 若客户对具体交付细节的询问只是了解性质、未进一步推进：回退到常规跟进节奏（参照S14），不强行逼单；若客户明确表示还需要考虑：转入S11相应异议处理，判断具体顾虑类型 |
| 使用注意 | 需确认该信号非孤立出现，最好同时伴随其他信号（如已确认价格）再推进 |

**S12-02｜信号：主动要求提供合同/相关文件**

| 字段 | 内容 |
|---|---|
| 编号 | S12-02 |
| 对话对象角色 | 采购经理 |
| 场景/触发条件 | 客户说"把合同/报价单发我看看" |
| 标准话术 | "好的，我马上把合同和报价单发给您。您看一下条款，如果没有问题，我们这边可以尽快安排走流程，您那边大概什么时候能确认？" |
| 禁忌话术 | 不要只是发送文件后就被动等待，缺少推进节奏的主动跟进 |
| 话术意图（四维度） | **情绪**：让客户感到流程顺畅、高效；**信息目标**：了解客户内部确认合同大概需要多长时间，便于后续跟进节奏安排；**关系**：展现响应迅速的专业度；**行动导向**：约定明确的后续确认时间点，而非无限期等待 |
| 升级路径 | 若发送文件后客户长时间未回应：参照S14长周期跟进节奏表安排跟进；若客户提出条款异议：转入S13-02/S13-03合同讲解流程或S11相关异议处理 |
| 使用注意 | 文件应在信号出现后尽快发送（当天为宜），避免客户购买意愿随时间衰减 |

## 三、案例公司乙（技术把关人/分管领导）

**S12-03｜信号：技术把关人要求提供正式技术对接人联系方式**

| 字段 | 内容 |
|---|---|
| 编号 | S12-03 |
| 对话对象角色 | 技术把关人 |
| 场景/触发条件 | 技术把关人说"后续对接技术细节，方便留一下你们技术负责人的联系方式吗" |
| 标准话术 | "当然可以，我这就把我们技术负责人的联系方式发给您，后续技术对接和实施细节都可以直接跟他确认。方便问一下，咱们这边大概是往哪个方向推进了，还需要我们配合准备哪些材料？" |
| 禁忌话术 | 不要仅提供联系方式就结束对话，错失进一步确认项目推进阶段的机会 |
| 话术意图（四维度） | **情绪**：让技术把关人感到我方响应及时、专业；**信息目标**：借机了解项目内部推进的实际阶段（是否已进入执行准备）；**关系**：巩固技术层面的信任基础；**行动导向**：引导技术把关人透露项目下一步安排 |
| 升级路径 | 若技术把关人不愿透露更多项目进展：不强行追问，保持正常配合姿态，通过S05决策链地图持续观察其他角色动态 |
| 使用注意 | 这类信号通常出现在方案已获得技术层面认可之后，需结合S08、S09阶段的进展综合判断信号强度 |

**S12-04｜信号：分管领导主动提及内部审批流程节点**

| 字段 | 内容 |
|---|---|
| 编号 | S12-04 |
| 对话对象角色 | 分管领导 |
| 场景/触发条件 | 分管领导说"这个方案我们内部已经在走审批了，大概下周能有结果" |
| 标准话术 | "了解，非常感谢推进。如果审批通过，我们这边可以立即启动准备工作，确保不耽误项目进度。如果审批过程中有需要我们补充的材料，随时和我说，我们尽快配合。" |
| 禁忌话术 | 不要在审批结果未出来前就催促"能不能加快""能不能提前给个准信"，容易显得不够尊重内部流程；不要停止跟进等待结果，而应主动询问是否需要配合材料 |
| 话术意图（四维度） | **情绪**：传递"我们随时准备好、全力配合"的可靠感；**信息目标**：了解审批流程的具体时间节点，便于后续跟进安排；**关系**：尊重客户内部流程节奏，不施压；**行动导向**：为审批通过后立即启动合作做好准备，同时主动提供配合空间 |
| 升级路径 | 若约定的审批时间节点已过、客户未主动告知结果：按约定时间点后1-2天礼貌跟进询问进展，不越级直接联系更高层催促；参照S14长周期跟进节奏表安排后续跟进频率 |
| 使用注意 | 此类信号强度较高，但不代表可以省略后续确认动作，仍需按约定节点主动跟进 |

## 四、信号不明确时的主动试探技巧（新增，弥补"只能被动等信号"的缺口）

现实中经常出现方案讲解完毕后，客户既无明显抗拒、也未主动展现购买信号，处于"不上不下"的拖延状态。此时销售不应只被动等待信号出现，而应主动使用**试探性问题**（trial close）温和地测试客户购买温度，这既能帮助识别客户真实状态，也能推进决策进程。

**S12-05｜甲：主动试探（采购经理，方案讲解后无明显信号）**

| 字段 | 内容 |
|---|---|
| 编号 | S12-05 |
| 对话对象角色 | 采购经理 |
| 场景/触发条件 | 方案讲解完毕，客户既未表现出抗拒也未主动展现购买信号，沉默或泛泛回应"再看看" |
| 标准话术 | "如果我们能在价格和交期上都满足您刚才提到的这些要求，您这边大概这周内能定下来吗？" |
| 禁忌话术 | 不要用"到底买不买"这种直接、生硬的封闭式逼问；不要连续追加多个试探性问题造成压迫感，一次试探即可，给客户反应空间 |
| 话术意图（四维度） | **情绪**：以轻松、假设性的语气降低客户的决策压力，而非直接施压；**信息目标**：通过客户对"如果……是否……"这一假设句式的反应，判断其真实顾虑是否已经消除；**关系**：保持温和试探而非强硬逼单的姿态；**行动导向**：促使客户要么明确表态、要么说出真实的剩余顾虑 |
| 升级路径 | 若客户明确回应"可以"：立即推进至S12-01/S12-02对应动作；若客户回避或提出新顾虑：转入S11对应异议类型处理，而非重复试探；若连续试探仍无实质回应：回退至常规跟进节奏（参照S14），避免多次逼问引起反感 |
| 使用注意 | 试探性问题一次为宜，不宜连续追问多个假设句式，否则容易变成变相施压 |

**S12-06｜乙：主动试探（分管领导/技术把关人，方案讲解会后无明显信号）**

| 字段 | 内容 |
|---|---|
| 编号 | S12-06 |
| 对话对象角色 | 分管领导或技术把关人（视讲解会主要对接对象而定） |
| 场景/触发条件 | 方案讲解会结束，客户未明确表态支持或反对，仅表示"我们内部再讨论一下" |
| 标准话术 | "理解，这种规模的项目内部讨论确实需要时间。如果技术和商务这边都没有大的问题，按目前的情况，您预计大概什么时候能给到我们一个初步的反馈方向？" |
| 禁忌话术 | 不要追问"到底还有什么问题"这种带质疑意味的说法；不要在客户明确表示需要时间时仍继续施加压力式提问 |
| 话术意图（四维度） | **情绪**：以尊重决策节奏的姿态获取一个大致的时间预期，而非施压式逼问；**信息目标**：获取一个可供后续跟进参照的大致时间节点，即使不是确定承诺；**关系**：维护决策层级的专业信任，不因追问而显得急躁；**行动导向**：为后续跟进设定一个参照时间点，避免陷入无限期被动等待 |
| 升级路径 | 若客户给出大致时间节点：按该节点安排跟进（参照S14）；若客户回避给出任何时间预期：不强行追问，转为常规跟进节奏观察，同时通过S05决策链地图关注其他角色是否释放信号 |
| 使用注意 | 乙的决策周期长，试探性问题的目的是获取"参照时间点"而非直接的购买承诺，预期管理需要与甲区分开 |

## 五、逼单力度与客户分层的关联

不同分层客户，逼单的语气和频率应有差异，避免"一刀切"：

| 客户分层 | 逼单方式调整 |
|---|---|
| S/A类（高价值） | 逼单语气可更主动、更频繁地表达合作意愿，因为该客户值得投入更多推进资源；参照S04对应权限，可适度提供更有吸引力的条款加速成交 |
| B/C类（一般价值） | 逼单保持常规节奏，不必过度追加资源投入，按标准流程推进即可 |

## 六、多次逼单未成功的处理

| 情况 | 处理方式 |
|---|---|
| 逼单后客户仍犹豫不决，超过1-2周无明确答复 | 不持续重复逼单话术，转为参照S11异议识别与拆解指南，判断客户真实顾虑类型（价格/信任/决策延迟等），针对性处理而非机械重复推进 |
| 多次逼单后客户明确表示暂不考虑 | 礼貌接受，转入S14常规跟进节奏，不做纠缠式追问，保持关系为未来可能的合作机会留有余地 |

## 七、本模块专属验收细则

| 检查点 | 标准 |
|---|---|
| 信号识别指南存在 | 是否说明如何区分真实信号与易误判信号，而非直接进入逼单话术 |
| 话术意图四维度完整 | 情绪、信息目标、关系、行动导向四项均需填写 |
| 升级路径明确 | 每条话术是否说明信号不明确/客户未进一步推进时该怎么办 |
| 主动试探技巧是否覆盖 | 是否包含信号不明确时主动试探的话术，而非只有被动等待信号出现 |
| 分层关联体现 | 是否说明不同客户分层下逼单力度的差异 |
| 多次未成功的处理存在 | 是否说明持续逼单不成功时该如何调整，而非无限重复施压 |
| 编号完整 | 每条话术是否有唯一编号 |

## 八、课件页要点

1. 强调"单一信号不代表可以逼单"，需要结合S03诚意判定交叉验证，避免把疑似比价客户的反复确认误判为购买信号。
2. 讲解逼单力度应结合S04客户分层调整，S/A类客户可以更主动，避免对所有客户使用同一种强度。
3. 讲解主动试探技巧和被动信号识别的区别与配合使用时机——没有信号不代表只能等待，可以主动、温和地试探。
4. 强调"多次逼单不成功"时不要机械重复，而应转向异议识别（S11），先搞清楚真实顾虑再对症处理。
5. 现场练习：给学员几个模拟场景（含真实信号、易误判信号、无明显信号三种），让其判断该用被动接应话术还是主动试探话术，导师用验收细则点评。
