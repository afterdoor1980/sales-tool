# S20 竞品对比话术

> 版本：v1.0（正式稿）
> 篇章：十二、竞争应对篇
> 模板类型：混合（类型C2对比矩阵清单 + 类型A主动对比/转化话术）
> 适用业务模式：甲乙对比
> 前置依赖：S11（竞品对比类异议的反应式话术，与本模块是"工具"与"应用"关系）、S05（不同角色关注的对比维度不同）、S02（差异化卖点是对比矩阵的素材来源）、S04（分层影响对比材料投入程度）、S08（需求挖掘承接转化后续）
> 模块目的：让销售在客户拿竞品比较时能理性拆解、体现专业性，而非陷入单纯比价或诋毁竞品；同时提供主动争取竞品存量客户的策略

---

## 一、与S11的边界说明

**S11竞品对比类异议**（S11-05、S11-10、S11-11）是"客户主动提出竞品比较时的反应式应答话术"，针对单一触发场景给出一句标准回应。**S20是这些应答背后的系统性工具**：竞品对比矩阵（多维度横向比较的素材库）、主动引导对比的策略、以及主动争取竞品存量客户的转化策略。两者关系是"S20提供弹药和框架，S11是弹药用在具体异议场景时的具体台词"。

---

## 二、竞品对比矩阵模板（类型C2）

| 对比维度 | 我方情况（示例） | 常见竞品情况（示例，需按实际竞品替换） | 差异化话术要点 |
|---|---|---|---|
| 价格 | 略高于最低价竞品，但含质检+补货保障 | 部分竞品低价但无额外保障条款 | 参照S11-01/05：引导对比全生命周期成本而非单价 |
| 交期稳定性 | 72小时紧急补货能力，批次交付记录可查 | 部分竞品交期波动较大，无书面记录 | 参照S02-01卖点话术 |
| 质量可追溯性 | 批次质检报告+可追溯编号 | 部分竞品无批次追溯机制 | 参照S02-02卖点话术 |
| 资质/案例背书 | 可提供同行业案例及联系人核实 | 视竞品实际情况填写 | 参照S05分管领导/技术把关人话术 |
| 服务响应 | 明确响应时限（参照S17服务标准） | 视竞品实际情况填写 | 强调书面承诺而非口头保证 |

**使用说明**：此矩阵需按实际接触到的具体竞品定期更新（建议每季度收集一线反馈更新一次），不能是一次性填写后不再维护的静态表格。填写时严禁编造竞品的负面信息，只能基于真实、可核实的公开信息或客户反馈。

**分层关联的投入差异**：面对S/A类高价值客户，建议投入更定制化的对比材料准备（如现场对比演示、第三方检测报告、定向邀请参观产线）；B/C类客户使用标准矩阵内容即可，不额外投入定制化准备资源。

## 三、按决策链角色差异化的对比重点（关联S05）

不同角色关心的对比维度不同，主动对比时应针对性突出：

| 角色 | 该角色最关心的对比维度 |
|---|---|
| 采购经理（甲） | 价格、交期 |
| 老板/总经理（甲） | 长期合作稳定性、供应链风险 |
| 技术把关人（乙） | 技术参数匹配度、方案可行性验证 |
| 财务（乙） | 全生命周期成本而非单纯报价 |
| 招标办（乙） | 资质完整性、合规性 |
| 分管领导（乙） | 案例背书、责任保障机制 |

## 四、主动对比话术（区别于S11的被动应答）

**S20-01｜甲：主动引导对比（未等客户提竞品）**

| 字段 | 内容 |
|---|---|
| 编号 | S20-01 |
| 对话对象角色 | 采购经理 |
| 场景/触发条件 | 方案/报价讲解阶段，客户尚未主动提及竞品，但销售判断客户大概率在同时接触其他供应商（如中小企业采购常见多方询价） |
| 标准话术 | "我们了解到像您这样规模的企业，通常会同时对比几家供应商，这很正常。除了价格，建议您也可以关注一下交期稳定性和质量追溯这两块——这些往往是后期实际使用中影响更大、但容易被忽略的部分。" |
| 禁忌话术 | 不要主动点名具体竞品名称进行比较，容易显得有针对性或不打自招地暴露对客户询价对象的揣测；不要暗示竞品有问题，而应引导客户自己用这些维度去对比 |
| 话术意图（四维度） | **情绪**：以专业顾问姿态而非推销姿态引导，降低客户的比价压迫感；**信息目标**：引导客户用对我方有利的维度（而非单一价格）进行综合评估；**关系**：展现自信和专业度，而非害怕比较；**行动导向**：让客户在后续比价时主动关注交期、质量等维度 |
| 升级路径 | 若客户后续明确提及具体竞品对比：转入S11-01/05对应反应式话术；若客户未再提及：不必追问，保持自然 |
| 使用注意 | 主动引导对比只适合在客户明确进入比价阶段（如已获取多家报价）时使用，不宜在初次接触阶段就主动挑起竞品话题 |

**S20-02｜乙：主动引导对比（方案评审阶段）**

| 字段 | 内容 |
|---|---|
| 编号 | S20-02 |
| 对话对象角色 | 技术把关人或招标办 |
| 场景/触发条件 | 方案评审阶段，多家供应商同时参与评估，销售判断需要主动建立评估标准的话语权 |
| 标准话术 | "考虑到这类项目通常会有多方比选，我们建议评估时除了报价，也可以重点关注方案与现场实际工况的匹配度，以及过往同类项目的可验证案例——这两点往往比单纯参数堆砌更能反映真实的实施风险。" |
| 禁忌话术 | 不要暗示评审标准应该被我方主导修改，避免引发合规质疑；不要点名具体竞品 |
| 话术意图（四维度） | **情绪**：以专业建议者姿态影响评估维度，而非直接干预评审公正性；**信息目标**：引导评审方关注对我方有利的维度（匹配度、可验证案例）；**关系**：维护合规、公正的评审印象；**行动导向**：让评审方在评估时纳入这些维度 |
| 升级路径 | 若客户后续明确提出具体竞品参数对比：转入S11-11对应反应式话术 |
| 使用注意 | 此话术仅适合在合规范围内使用，不得有任何暗示操纵评审结果的表述 |

## 五、竞品客户转化策略（新增，对应原课程材料"抢夺对手客户"核心场景）

前述内容处理的是"评估阶段的横向对比"，本节处理更主动、更具体的场景：**客户当前是竞品的存量客户，我方主动接触争取转化**。

### 识别信号：该客户当前在用竞品

| 案例 | 识别信号 |
|---|---|
| 甲 | 客户在询价/沟通中提及"我们现在合作的供应商是XX"，或询价参数明显对标某竞品的规格/条款 |
| 乙 | 客户官网/公开信息显示曾用某竞品完成类似项目，或客户主动提及"目前产线用的是XX的设备/方案" |

### 切入时机判断

| 案例 | 最佳切入时机 |
|---|---|
| 甲 | 客户对现有供应商流露出些许不满信号时（参照S11异议识别与拆解指南的模糊表述判断方法）是最佳窗口；客户对现有供应商明显满意时不宜强行切入 |
| 乙 | 通常在客户业务扩张、需要新增供应商（而非直接替换现有稳定供应商）时机更好；直接要求替换现有正常运作的供应商，成功率通常很低，不建议作为首要策略 |

**S20-03｜甲：竞品客户初步接触话术**

| 字段 | 内容 |
|---|---|
| 编号 | S20-03 |
| 对话对象角色 | 采购经理 |
| 场景/触发条件 | 得知客户现有供应商是某竞品，希望建立联系争取未来合作机会 |
| 标准话术 | "了解到您这边目前和XX有合作，我们不是想说服您马上更换，而是想先建立一个联系，如果未来有额外的备选采购需求，或者现有合作出现任何波动，我们随时可以作为一个可靠的备选方案。" |
| 禁忌话术 | 不要一开始就要求客户"换掉现有供应商"，这种要求成功率低且显得冒犯；不要诋毁客户现有的供应商 |
| 话术意图（四维度） | **情绪**：以低压力、非替代性的方式建立联系，避免让客户产生"背叛现有供应商"的心理负担；**信息目标**：了解客户对现有供应商的满意度和潜在备选需求；**关系**：建立"低风险备选方案"的定位，而非直接对抗式竞争；**行动导向**：让客户愿意保留联系方式，为未来机会窗口做铺垫 |
| 升级路径 | 若客户透露对现有供应商有不满（参照S11识别指南的模糊表述判断方法）：可加大接触频率，参照S08需求挖掘深入了解具体不满点；若客户明确表示满意度很高、无更换意愿：保持低频关系维护（参照S14终止规则的逻辑），不强行推进 |
| 使用注意 | 此类话术更适合作为长期埋线的第一步，不要期望一次接触就能转化 |

**S20-04｜乙：竞品客户初步接触话术**

| 字段 | 内容 |
|---|---|
| 编号 | S20-04 |
| 对话对象角色 | 技术把关人或分管领导 |
| 场景/触发条件 | 得知客户当前使用某竞品设备/方案，希望建立联系争取未来项目机会 |
| 标准话术 | "了解到贵司目前的产线上使用的是类似XX的设备方案，如果后续有产能扩张或者设备更新换代的计划，我们很乐意提供一版技术方案供参考对比，不一定非要马上决定，可以先了解一下我们在类似场景下的经验。" |
| 禁忌话术 | 不要直接说现有方案"不够好"或质疑客户当初的选择；不要暗示可以无边界地免费提供大量前期方案调研 |
| 话术意图（四维度） | **情绪**：以增量合作而非替代对抗的方式接触，降低客户的防御心理；**信息目标**：了解客户是否有扩张/更新换代计划，这是介入的最佳窗口；**关系**：建立长期潜在合作伙伴关系，而非追求短期立即成交；**行动导向**：获得进一步技术交流或方案参考的机会 |
| 升级路径 | 若客户明确表示有相关计划：进入S08需求挖掘阶段；若客户表示暂无计划：保持低频关系维护，定期分享行业技术动态（参照S06渠道内容运营逻辑） |
| 使用注意 | 乙的转化周期通常更长，需要有耐心，不宜期待短期内促成替换现有供应商 |

## 六、劣势维度应对策略（新增，处理我方确实处于劣势的对比场景）

对比矩阵中并非所有维度我方都占优，需要有诚实且不失专业性的应对策略，而非回避或勉强狡辩：

| 情况 | 应对策略 |
|---|---|
| 价格明显劣势 | 不否认价格差异，转向全生命周期成本或综合价值论证（参照S11-01/S11-06逻辑），不通过贬低对方来掩盖自身价格劣势 |
| 某项技术参数确实逊色 | 坦诚承认该单项参数的客观差距，但强调该参数在客户实际使用场景中的实际影响程度（如"这个参数差异在您的实际工况下影响有限"），将焦点转移到匹配度而非参数堆砌（呼应S11-11逻辑） |
| 品牌知名度/市场份额劣势（新进入市场或规模较小） | 强调灵活性、响应速度、定制化服务能力等大公司难以提供的优势，重新定义竞争维度而非在知名度上正面较量 |
| 交期/产能规模劣势 | 如实说明产能情况，同时强调质量控制的严谨性或按单定制的精细度作为补偿性价值 |

**核心原则**：承认劣势本身不会立即导致失败，不诚实或试图转移视线才会；客户往往能感知到刻意回避的话题，坦诚反而增强可信度，再顺势引导到更能体现我方综合竞争力的维度上。

## 七、竞品对比的职业道德红线

| 红线 | 说明 |
|---|---|
| 不得编造竞品负面信息 | 所有关于竞品的陈述必须基于真实、可公开核实的信息，不得凭空捏造质量问题、财务问题等 |
| 不得诋毁竞品声誉 | 即使掌握真实的竞品负面信息，表达方式也应克制、客观，不使用贬低性语言 |
| 不得非法获取竞品信息 | 不通过不正当渠道（如竞品离职员工泄密、非公开商业机密）获取对比信息 |

## 八、本模块专属验收细则

| 检查点 | 标准 |
|---|---|
| 对比矩阵维度完整 | 是否覆盖价格、交期、质量、资质、服务等主要维度，且矩阵有更新机制而非一次性静态表格 |
| 分层投入差异是否说明 | 是否说明S/A类客户值得投入更定制化的对比材料，B/C类用标准矩阵即可 |
| 与S11边界清楚 | 是否说明本模块是工具/框架，S11是具体反应式话术，两者不重复 |
| 决策链角色关联 | 是否说明不同角色关心的对比维度差异，而非用同一套对比重点应对所有角色 |
| 主动对比使用时机明确 | 是否说明何时适合主动引导对比、何时不宜，而非默认随时可用 |
| 竞品客户转化策略是否覆盖 | 是否包含识别信号、切入时机、初步接触话术，对应原始素材"抢夺对手客户"的核心场景 |
| 劣势维度应对策略存在 | 是否说明我方处于劣势时该如何应对，而非只展示优势维度的对比内容 |
| 职业道德红线明确 | 是否明确不得编造/诋毁/非法获取竞品信息 |
| 编号完整 | 每条话术是否有唯一编号 |

## 九、课件页要点

1. 讲解S20与S11的关系：S20是"平时要准备的弹药库和主动出击策略"，S11是"遇到具体场景时用哪句台词"。
2. 强调主动对比不是主动攻击竞品，而是主动引导客户关注对我方有利的维度。
3. 讲解竞品客户转化策略，强调"先建立低压力联系、等待时机"而非"上来就要求换供应商"，管理好转化周期的预期。
4. 讲解劣势维度应对策略，让学员理解坦诚劣势比勉强狡辩更有说服力。
5. 强调职业道德红线，即使了解竞品真实的负面信息也要克制表达方式。
6. 现场练习：给学员一份本企业实际的竞品清单，让其填写竞品对比矩阵，针对不同角色设计一条主动引导对比话术，并练习一次"我方处于劣势维度"的模拟应对。
