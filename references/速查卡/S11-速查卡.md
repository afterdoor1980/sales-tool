# S11 速查卡 — 高频异议（价格类 · 甲 · 采购经理）

> 对齐来源：S11 高频异议应对话术库 v1.6 · 价格类 · S11-01
> 使用提示：本卡只覆盖"价格类 · 甲类客户 · 采购经理"一个格子；其余格子（老板/乙类财务·技术/信任/竞品/预算延迟等）见 S11 正文"异议场景三维定位"锚定表。

---

## ① 锚定坐标（先定位、再开口）

定位三步：**这是哪类异议**（价格 / 竞品 / 信任 / 预算）？→ **对谁说**（采购经理 / 老板 / 财务 / 技术 / 分管 / 招标办）？→ **属哪个业务模式**（甲 / 乙）？

本卡格：**价格类 · 甲 · 采购经理** → S11-01
- 大额介入、老板亲自谈价 → S11-02
- 乙类价格异议 → S11-06（财务/预算）· S11-07（技术把关人）
- 一句话含多类信号 → 先按 S11 第一节识别拆解，锚到真实异议类型，而非被表面话术带偏

## ② 一句话口诀

别当场让价，把"压价"转成"一起算总账"——先用质检报告 + 补货承诺论证单价，再引到年度框架协议上锁价。

## ③ 代表话术（可直接照读 · 出自 S11-01）

> "理解您想控制成本。我们这个价格里包含了每批次的质检报告和 72 小时紧急补货承诺——如果按单价对比，XX 厂能做到吗？我们可以看看您的采购量，是否能通过年度框架协议锁定更优价格。"

**禁忌**：不要说"我们价格已经是最低了"；不要主动大幅让价。
**升级**：仍要求直接降价 → 转 S10-03 年度框架让价（而非单笔让价）；降价幅度超本人报价权限 → 转主管确认，不自行拍板。
